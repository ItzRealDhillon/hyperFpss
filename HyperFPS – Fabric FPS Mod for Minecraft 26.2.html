How to download & install

Four quick steps and you are in game.

🧩

Get Fabric

Install Fabric Loader 0.19+ for Minecraft 26.2 (Java 25+ needed) and create a Fabric profile in your launcher.

📥

Download the files

Press Download, choose 26.2 + Fabric, then also grab Fabric API (required) and optionally Sodium.

📁

Drop into mods

Open your .minecraft/mods folder (create it if missing) and put the .jar files in (unzip the HyperFPS download first). Keep only one HyperFPS jar.

🚀

Launch & enjoy

Start the Fabric profile. In game press Right Shift to open the HyperFPS HUD editor and settings.

⚡ Want even more FPS? Add Sodium

Sodium is a separate rendering-optimization mod that pairs well with HyperFPS. Check that it supports your Minecraft version.
